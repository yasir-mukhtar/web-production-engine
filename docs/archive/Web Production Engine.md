
# What we are building

We are building a marketing website production agency to help SMB in Indonesia build their online presence. SMB wants the customers to discover them, but they don't have big budgets like corporations. This market is not sexy to the web agencies and top tier freelancers because SMB doesn't have big budgets.

We are filling the gap by providing high-quality, custom-like websites with the help of AI agents and unique tech stacks available on the internet, such as Shadcn for UI components, Cloudflare Pages for hosting, Pages CMS for the CMS, and more.

# How it works

This is the expected workflow in high level:

1. Founder discuss with client to get general requirements and brief, such as website goal, company name, preferred URL, products/services, benefits, value propositions, ideal target customer, testimonials, recognition/awards, competitors, contact, social media profiles, and could be more.
2. Those informations will be passed to an AI agent. This AI agent are equipped with skill to translate those brief into an information architecture, content strategy, content writing, including what images to create (create the prompt to create the image), web wireframe.
3. Founder will review, give feedback, reject, or approve the draft.
4. After approved, another AI agent will make a comprehensive plan to develop the whole web stack: the frontend frameworks, the CMS integration, the infra, the SEO, the security, and other necessary aspects. This agent then implement the plan until we got a live URL.
5. Client will review the live URL. Founder can come back to AI agent to do some revisions.
6. After done, the web could be handed over to the client (the repo, cloudflare, CMS account, and others that is not mentioned yet).
